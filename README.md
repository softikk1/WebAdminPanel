## WebAdminPanel

Админ панель, нужная для обслуживания сайтов. 

Эта система специализируется на том, чтобы изменять отображение и информационные внутренности сайта, не заходя в его код напрямую.

(Экспериментально. Пока изменять можно только текст с помощью ключей. Код запроса внедряется в сайт, а после происходит парсинг по ключам).
